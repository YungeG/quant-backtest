# G12H Rule Coverage

## Outcome

Eventually prove complete, non-overlapping historical coverage for every rule dimension explicitly required by one immutable market-profile declaration, without duplicating Kernel economics.

## Current status

`DRAFT / BLOCKED`. `MarketSemanticsProfileRegistration` has no `required_rule_dimensions()` authority, Builder cannot import Runtime/Kernel, and no normalized G12C rule-source schema or immutable profile-to-dimension declaration exists.

Research authority: `docs/research/g12h-rule-coverage.md`.

## Blocker to resolve first

Freeze a profile/build-owned declaration that binds profile identity, component manifest, exact required dimension keys, expected normalized rule-source schemas/source identities, coverage target, explicit empty semantics, and immutable artifact hash. Freeze at least one real normalized rule-source fixture plus test-only parity to the authoritative typed Kernel rule book.

G12H must consume this declaration; it must not invent dimensions from `ProfilePortType` or enumerate Kernel classes.

## Provisional implementation seam

Only after the prerequisite is PASSED may Builder add a pure atomic validator producing one `RuleCoverageReport` or one `RuleCoverageFailure`. The final public names, canonical bodies, failure codes, and RED matrix remain unfrozen until then.

## Readiness checks

Before changing `readiness` to `READY`, evidence must prove:

- exact profile/declaration/Bundle binding;
- one normalized source schema for each fixture dimension;
- complete half-open interval coverage and unique resolution;
- gap/overlap/source-identity failures and deterministic precedence;
- explicit zero-dimension behavior;
- no Runtime/Kernel production import or second rule engine;
- repeat canonical hashes and immutable fixture authority.

## Non-goals

No generic rule model, DSL, registry, evaluator, economic calculation, provider lookup, fallback, imputation, Runtime boot branch, decision-grade claim, or deployment authorization.
