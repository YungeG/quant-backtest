# G12B Canonical Normalization

## Outcome

Transform records from one explicitly frozen source grammar into existing canonical Domain/Market Data public values with deterministic source↔event provenance and no partial success.

## Readiness work

Research authority: `docs/research/g12b-canonical-normalization-contract.md`.

The detailed Gate contract is authoritative in the G12B Acceptance Card in `docs/implementation/acceptance-matrix.md`; this plan does not duplicate status.

The first source contract is frozen as provider-neutral Synthetic JSONL v1. It exists only to prove deterministic normalization mechanics before real G12L adapters.

## Frozen reusable boundary

G12B must reuse:

- G12A verified `SourceSnapshot.member_bytes()`;
- public `InstrumentId`, `UtcInstant`, `Scale`, `PricePurpose`, `TimelinePhase`, and `SourceSequence` contracts;
- public `MarketEvent` envelope and revision fields.

It must not import Trading Kernel profile types or Runtime revision wrappers. Generic Rule and CorporateAction typed records do not yet exist; G12B cannot invent them locally.

## Frozen first grammar

Synthetic JSONL v1 freezes exact member selection, physical-line locators, canonical JSON, finite Instrument/PricePurpose bindings, time/Scale mapping, Event identity, revision preservation, source trace, and structured failure precedence.

G12B deliberately adds Builder → Trading Domain public-root dependency. It does not add a generic parser/plugin system.

## Exclusions

No G12C manifest/coverage, G12G Bars, G12H/K economic coverage, G12I gap/revision selection, provider acquisition, publication, Reader, Runtime, or decision-grade claims.
