# G12F Reader and Partition Parity

## Outcome

Prove exact parity between `InMemoryMarketBundleReader` and `LocalMarketBundleReader` for one immutable Bundle identity through logical stream reads, deterministic Timeline output, Engine results, and G07 execution hashes.

## Research authority

`docs/research/g12f-reader-partition-parity.md` narrows v1 to the manifest-bound canonical payload representation that G12D/G12E actually own. Parquet/Arrow, physical partition alternatives, and memory mapping remain deferred until a separately hashed representation contract exists.

## Frozen candidate slice

G12F adds isolated parity tooling and no production export. Test/support code produces canonical projections for both Reader adapters and the existing Comparator Contract v1 proves exact equality and first divergence.

The compared identity layers are Bundle/Manifest, per-stream Event IDs/hashes, Timeline Event IDs/hashes/segments, execution-case hash, Engine result/Trace/Ledger/Snapshot/Run End hashes, and G07 execution result hash. Reader class, local root, Reader/Timeline batch size, Attempt ID, and Evidence Manifest hash remain operational or attempt evidence rather than economic identity.

## TDD order

1. Freeze the parity projection and exact comparator contract.
2. Prove Reader batch-size parity for in-memory and persisted adapters.
3. Prove Timeline batch-size and terminal Cursor parity.
4. Prove execution-case and direct Engine hash parity.
5. Prove G07 distinct-attempt/evidence identities bind one execution result hash.
6. Freeze first divergence for stream, Timeline, and execution mutations.
7. Freeze malformed/unclassified input, root independence, repeat bytes, and architecture isolation.

## Exclusions
