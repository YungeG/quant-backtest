# G12G Canonical Bar Aggregation

## Outcome

Implement one pure offline Builder compiler that validates a complete G12C source Bundle, consumes one explicit caller-supplied finite bucket plan, emits canonical revisioned exact price-only `bar` Events with full source/definition/bucket-plan/spec/code lineage, and revalidates the source-plus-Bar tuple through G12C.

G12G is frozen `PASSED` in `docs/implementation/acceptance-matrix.md` at implementation commit `eefe4df3568776323881810a309ea09a47b379b7`.

## Research authority

`docs/research/g12g-bar-aggregation.md` is the frozen v1 contract. It resolves the time-bucketing seam as one caller-supplied finite `BarBucketPlan`, not a calendar engine or bucket generator, and rejects ambiguous same-time economic ordering because G12B has no authoritative tie sequence.

## Implementation order

1. **Canonical values and hashes**
   - Implement strict immutable bucket, bucket-plan, definition, manifest, result, failure, and XOR outcome values.
   - Freeze nonrecursive hash bodies, exact SessionId/TradingDate/half-open-span binding, definition invariants, fixed spec identity, false qualification flags, and `dataclasses.replace` forgery controls.

2. **Source authority reuse**
   - Re-run `validate_market_bundle_v1` over the complete caller-order source tuple and require exact manifest equality.
   - Resolve exactly one declared source stream and reject output-stream collision.
   - Parse only exact G12B `synthetic_price_point.v1` payloads; select exact PricePurpose and Scale without sorting or rescaling.

3. **Caller-supplied finite bucket plan**
   - Validate the exact finite caller-order bucket tuple and its coverage without deriving, splitting, merging, truncating, or repairing buckets.
   - Require each bucket to bind one SessionId, one TradingDate, and one or more ordered disjoint half-open included spans.
   - Require the plan's exact BarDefinition identity and freeze bucket canonical bodies plus `bucket_plan_hash`.

4. **Assignment and exact OHLC**
   - Assign selected economic times to at most one supplied bucket by non-overlapping half-open included spans; retain no-match observations only as out-of-plan evidence.
   - Count out-of-plan revisions and empty instrument/bucket pairs mechanically without treating either as coverage or qualification.
   - Reject ambiguous distinct observation keys at one Instrument/economic time.
   - Compute price-only OHLC from exact integer units at one exact decimal denominator; volume remains null.

5. **Revision and availability lineage**
   - Mechanically validate one linear source chain per `(InstrumentId, synthetic_record_key)`.
   - Collapse pre-close changes into the root visible state, support late roots, and group same-UTC post-close changes before output.
   - Emit every changed selected-source-set state, retain old Bar revisions, and bind immediate supersession.
   - Fail when output phase cannot sort after causal source evidence at equal UTC.

6. **Output identities and final validation**
   - Derive Event/revision IDs, deterministic output ordinals, selected-source-set hash, aggregation input hash, and output Bundle key with explicit source-stream, definition, bucket-plan, spec, and code hashes.
   - Append generated Bars to unchanged source Events and rerun G12C; return no result unless final validation succeeds.
   - Derive output stream/Bundle refs, all mechanical counts, and atomic `BarAggregationManifest`.

7. **Golden, integration, and static evidence**
   - Freeze `canonical-bar-aggregation-v1` expected canonical JSON.
   - Prove G11D consumes exact `bar` Events with matching `BarDefinitionRef` and performs no resampling.
   - Keep bucket-plan/revision/availability coverage and provider/market qualification in G12I and G12L/M.
   - Add the scoped import-boundary rule and architecture mutation test.
   - Run upstream regressions, mypy, lock check, full suite, JUnit, and artifact hashing before any PASSED proposal.

## Explicit non-goals

- No bucket derivation, exchange calendar/timezone/DST/holiday calculation, included-phase inference, interval-completeness claim, or provider Session authority.
- No generic resampling DSL, callback, protocol, registry, calendar engine, bucket generator, DataFrame, Pandas, Polars, Arrow, or new dependency.
- No volume/VWAP/turnover, float/Decimal aggregation, rescaling, forward fill, carry close, zero/placeholder Bar, or cancellation revision.
- No provider/network/filesystem/database/subprocess/current-clock behavior.
- No Reader/repository/publication sidecar and no mutation of passed G12C/G12D schemas.
- No Runtime/Trading Kernel import, Strategy resampling, live mode, decision grade, or deployment authorization.
- No bucket-plan coverage, revision completeness, gap reason, price/availability completeness, provider truth, or real-market qualification; those remain G12I and G12L/M.
