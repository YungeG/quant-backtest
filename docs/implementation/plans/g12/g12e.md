# G12E Local Persisted MarketBundle Reader

## Outcome

Open one exact G12D local Bundle identity, verify the complete immutable publication before serving any event, decode the already-published canonical stream payloads, and implement the existing `MarketBundleReader` cursor contract.

## Research authority

`docs/research/g12e-persisted-market-bundle-reader.md` records the accepted decision to read the exact G12D canonical payload representation. Parquet/Arrow packaging is deferred until a separately hashed representation contract exists.

## Frozen vertical slice

One concrete `LocalMarketBundleReader` in `market-data-contracts` owns one classmethod `open(repository_root: Path, bundle_ref: MarketBundleRef)`. The opened object implements the existing WP-06A Reader methods without adding a second Protocol, Cursor, repository abstraction, callback, registry, or codec plugin.

Open verifies the G12D final exact-cover, read-only and symlink-free tree; canonical Manifest, publication, and retention evidence; Bundle identity; every stream payload hash; exact canonical JSON event tuples; and all existing in-memory Reader integrity rules before returning a Reader.

The absolute repository root is operational input only and never enters identity, Cursor evidence, canonical output, or error text.

No Parquet/Arrow, memory map, DataFrame, columnar writer, Builder import, generic repository Protocol, URI/object-store/database/network adapter, lazy partial verification, cache, Runtime outcome mapping, coverage qualification, retention guarantee, decision grade, or deployment authorization.
