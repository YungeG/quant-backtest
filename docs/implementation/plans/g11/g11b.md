# G11B Point-in-time Revision Selection and Causality

## Outcome

A Strategy-safe view bound to one `SimulationInstant` that returns only authorized, visible, latest legal revisions with canonical per-query causality evidence.

## Frozen contract

The detailed READY contract and commands are authoritative in the G11B Acceptance Card in `docs/implementation/acceptance-matrix.md`.

Research authority: `docs/research/g11b-observation-revision-causality.md`.

Core behavior:

- caller supplies explicit observation lineage keys;
- authorization precedes visibility and revision inspection;
- visibility uses full Simulation Instant ordering;
- future and unauthorized revisions cannot affect prior identity;
- each visible lineage must be a legal single chain;
- query results bind selected revisions, source hashes, dataset hash, and time maxima;
- G11A artifacts remain byte-for-byte compatible.
