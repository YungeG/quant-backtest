# G11J Precomputed-vs-Strategy Parity

## Outcome

A test-owned dual-entry fixture demonstrates that identical complete validated `TargetSnapshot` values produce the same existing DecisionBatch, Allocation, Risk, Active Target, Orders, Fills, Slippage, Fees, financial artifacts, Journal, Ledger, final Snapshot, Run End, Trace, Engine result, and G07 execution-result hash after source-neutral normalization.

## Frozen readiness contract

Research authority: `docs/research/g11j-precomputed-strategy-parity.md`.

G11J normalizes one precomputed Candidate and one G11I Strategy Candidate at the complete ordered validated `TargetSnapshot` seam. The fixture Candidate is source-neutral and contains fixed confidence, reason, and Decision evidence; it does not embed Strategy invocation `context_hash` evidence.

Current source batch identity remains explicit sidecar evidence: precomputed collection emits legacy v1 identity while G11I binds the full `SimulationInstant` in v2 identity. G11J neither compares nor strips those raw source batches inside economic layers. Layer 00 exact-compares the shared full instant, complete source-neutral validated Decisions—including confidence, reason, and Decision evidence—and TargetSnapshots. It then binds both entries to independently composed equal normalized execution cases and lets the existing Engine form the common downstream batch.

The frozen exact layer order is:

```text
00_NORMALIZED_ENTRY
01_DECISION_BATCH
02_ALLOCATION
03_PORTFOLIO_RISK
04_NORMALIZED_ACTIVE_TARGET
05_ORDER_PLAN_INTENT
06_ORDER_EVENT
07_FILL
08_SLIPPAGE
09_FEE
10_FINANCIAL_ARTIFACT
11_JOURNAL
12_LEDGER
13_FINAL_SNAPSHOT
14_RUN_END
15_TRACE
16_EXECUTION_RESULT_HASH
```

Comparator Contract v1 rules use only `exact` and exact `sequence`. Numeric prefixes define first-divergence precedence. No tolerance, quantization, epsilon, approved change, ignored field, or not-comparable row is permitted.

Entry-only evidence is restricted to TargetStream digest/schedule/source/injection evidence; Strategy schedule/eligibility/artifact/checkpoint/context/invocation/state/output/handoff evidence; and the differing source batch IDs/hashes. G07 Attempt IDs and Evidence Manifest hashes remain distinct operational evidence. No economic object after normalization is excluded.

## Failure contract

- unsafe input path: `BLOCKED`, exit `2`;
- malformed or unclassified contract/projection: `BLOCKED`, exit `2`;
- first differing numbered layer: `MISMATCH`, exit `1`;
- all exact layers equal: `MATCH`, exit `0`.

A later aggregate hash cannot hide an earlier layer difference. Qualification flags remain false.

## Assurance boundary

`MATCH` means only that the supplied expected and actual projections satisfy the frozen contract and compare equally. The CLI does not regenerate them, inspect the sidecar, or authenticate their precomputed/Strategy provenance; identical substituted or malicious files can also match. The dual-entry generation test separately executes both entry mechanisms and checks the resulting projection and sidecar fixtures.
