# G08H A-share Profile Composition and Parity

## Status

`DRAFT / BLOCKED`. G08A–G08G are `PASSED`, but G08H does not yet have an exact public seam, typed scope/revision declarations, failure precedence, profile manifest, Runtime Journey contract, parity layer policy, fixtures or RED tests.

Research authority: `docs/research/g08h-profile-composition-parity.md`.

## Goal

Compose the frozen A-share components into one development-only `equity.cn_a_share.v1` resolved profile, exercise it through existing profile-neutral Runtime seams, and report the exact boundary between comparable legacy behavior and `NOT_COMPARABLE_LEGACY_SCOPE` behavior without claiming real-market qualification.

## Non-negotiable boundaries

- Production composition belongs in one pure `backtest-runtime` module; no second registry, resolver, engine, dispatcher framework or cache.
- Development dispatcher/Journey wiring belongs in `tests/support` and reuses the G09H profile-neutral financial-dispatch seam; Engine, Runner, Timeline, Journal and Ledger remain profile-neutral.
- G08A–G08G values remain the only component authorities.
- Caller-supplied qualification and revision-closure evidence must be immutable, canonical and explicit; no symbol-prefix, current-state or provider inference.
- G08G already rejects every tax disposition except `NOT_APPLICABLE`; G08H v1 preserves that exclusion and does not invent deferred-tax Lot state.
- XSHG bonus/capitalization remains unsupported.
- All outputs remain development-grade with decision/profile/deployment qualification flags false.

## Milestone F0 — Readiness contract freeze

Before implementation, freeze in the Acceptance Matrix:

1. exact production module path and exported names;
2. immutable instrument-scope, account-scope, announcement-closure and register-closure declaration schemas, including exact source-snapshot/coverage/availability identity; the composer validates the supplied set/chain but does not prove external provider/archive completeness;
3. distinct cross-query identity-history validation inputs;
4. complete 12-slot Market Profile manifest, Simulation Profile manifest, Execution Account Profile, component keys/digests and capabilities;
5. composer failure enum and first-failure precedence;
6. development dispatcher key, payment/listing operation keys, payload identity and atomic failure mapping;
7. static composition/Journey/parity fixture IDs, exact commands and artifacts;
8. exact legacy/G08H parity layers and `MATCH`/`MISMATCH`/`APPROVED_CHANGE`/`NOT_COMPARABLE` policy.

F0 ends only when RED tests and fixtures are independently reviewed and frozen. Current status is blocked at F0.

## Milestone F1 — Pure resolved-profile composition

Implement one production deep module analogous to G10G. It consumes only caller-supplied frozen authorities, validates scope/revision/identity/time coverage, constructs existing generic registrations and returns strict XOR success/failure values. It performs no filesystem, network, provider, database, process or wall-clock access.

## Milestone F2 — Development dispatcher and Journey

Implement test-support-only A-share dispatch wiring using the existing `FinancialEventDispatcher` seam. The Journey must cover:

- G08A Session/Calendar;
- G08B T+1 settlement and Journal-prefix binding;
- G08C quantity lattice and G08D order rules/price limits;
- G08E fee/tax;
- G08F entitlement;
- G08G cash payment and XSHE share delivery through phases 110/120;
- Journal/Ledger full, prefix and resume reconstruction;
- exact failure without partial effects for unsupported tax/scope/lifecycle cases.

No `CnAShare*` import or operation branch may enter generic Runtime modules.

## Milestone F3 — Layered legacy scope/parity report

Use WP-00C/G10H patterns without claiming unsupported equality. `cycle-rotation-platform` lacks authoritative Calendar, T+1, historical fee/tax, price-limit and Corporate Action semantics, so those layers must be explicitly classified as not comparable unless another immutable oracle is supplied. Any comparable layer must use exact projections and locate the first divergence deterministically.

## Milestone F4 — Acceptance

Run focused composition, Journey, golden, parity and architecture commands; full repository pytest; mypy; import boundaries; LSP/pi-lens; `uv lock --check`; and `git diff --check`. Freeze artifact hashes and obtain independent correctness/accounting/API/parity reviews before `PASSED`.
