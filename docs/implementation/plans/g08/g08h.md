## Declaration schemas

Every declaration is immutable/slotted, uses `schema_version=1`, exposes `to_canonical_dict()`, and derives a property `declaration_hash = canonical_sha256(canonical body)`. The hash is not a caller-supplied dataclass field and never enters its own preimage.

### Instrument scope

`CnAShareInstrumentScopeDeclaration` fields are exact:

1. `instrument: InstrumentDefinition`
2. `rule_context: CnAShareInstrumentRuleContext`
3. `coverage_from: UtcInstant`
4. `coverage_to_exclusive: UtcInstant`
5. `available_at: SimulationInstant`
6. `is_ordinary_domestic_a_share: bool`
7. `is_standard_cash_auction: bool`
8. `is_b_or_h_share: bool`
9. `is_fund_or_bond: bool`
10. `is_stock_connect: bool`
11. `has_lending_or_repo: bool`
12. `has_pledge_or_freeze: bool`
13. `is_restricted_or_pre_ipo: bool`
14. `has_differential_distribution: bool`
15. `has_issuer_self_distribution: bool`
16. `source_snapshot_hash: str`
17. `source_manifest_hash: str`

Success requires XSHG/XSHE broad Equity, quote/settlement CNY, ordinary domestic standard cash auction, and every excluded-scope flag false. `rule_context` is the existing G08D board/risk/listing authority; the composer does not infer these facts from symbol text.

### Account scope

`CnAShareAccountScopeDeclaration` exact-fields are account ID, `VenueId`, finite coverage, full `available_at`, explicit cash/domestic assertions, margin-or-short permission, Stock Connect permission, available-margin authorization, source snapshot hash and source manifest hash. Success requires cash domestic access and all three permissions/authorizations false.

### Announcement/register revision sets

`CnAShareAnnouncementRevisionSetDeclaration` binds Venue, Instrument, corporate-action ID, caller-order `revision_chain: tuple[tuple[str, str | None, str], ...]`, terminal revision ID, cancellation state, finite coverage, availability and source snapshot/manifest hashes.

`CnAShareRegisterRevisionSetDeclaration` binds Account, `PositionBalanceKey`, register-series ID, the same revision-chain shape, terminal revision ID, finite coverage, availability and source snapshot/manifest hashes.

Each chain must be nonempty, unique, immediate-parent linear and terminate at the declared ID. Announcement cancellation fails closed. G08H validates only the supplied set/chain and its source identities; it does not prove an external provider/archive omitted nothing.

### Cross-query identity history

`CnAShareIdentityHistoryDeclaration` stores canonical tuples of `(scoped_identity_key, payload_hash)` for corporate actions, register snapshots and register revisions, plus finite coverage, availability and source snapshot/manifest hashes. Tuples are canonical-sorted. Reusing one scoped key with a different payload hash is `CROSS_QUERY_IDENTITY_CONFLICT`.

Malformed exact types, noncanonical text/hash values or invalid finite intervals are constructor errors. Supported-scope booleans, chain closure, cancellation, identity conflict, coverage and availability remain structured composition failures.

Canonical type literals and exact field order are frozen in `tests/fixtures/runtime/profiles/cn-a-share-resolved-profile-composition-v1.json`.

## Composition request and identity

`CnAShareProfileCompositionRequest` exact-fields are five optional declarations; exact G08A frozen Calendar; G08D Order Rule Book; G08E Market Fee and Stamp Duty Rule Books; G08F Corporate Action Entitlement Rule Book; canonical tuples of Entitlements, G08G Cash Payment Requests and Share Delivery Requests; finite `TimelineWindow`; and `SimulationInstant composed_at`.

The five declarations are optional only to permit structured missing-authority failures. All inherited G08 rule books and tuples use exact concrete types. Entitlement/payment/share tuples are constructor-canonicalized by frozen identity order; revision chains retain caller semantic order.

`request_hash` is `canonical_sha256(request)`. Changes to any declaration, inherited authority, entitlement/request, time boundary or availability must propagate to request, model, profile, registration and dispatcher-spec identity.

The enum declaration and first-applicable order are exact:

1. `MISSING_INSTRUMENT_SCOPE`
2. `MISSING_ACCOUNT_SCOPE`

9. `REVISION_CLOSURE_MISMATCH`
10. `CROSS_QUERY_IDENTITY_CONFLICT`
11. `TIMELINE_COVERAGE_MISMATCH`
12. `EVIDENCE_NOT_AVAILABLE`
13. `UNSUPPORTED_TAX_DISPOSITION`
14. `UNSUPPORTED_XSHG_SHARE_DELIVERY`
15. `COMPONENT_IDENTITY_CONFLICT`

`AUTHORITY_CONTEXT_MISMATCH` covers Account/Venue/Instrument/currency mismatch across declarations, G08 rule books, Entitlements and G08G requests. Coverage must contain the full run window; every evidence availability must be at or before `composed_at`.

G08G success remains `NOT_APPLICABLE`-only. `APPLIED` and `DEFERRED_UNSUPPORTED` fail before Journal/Lot effects. XSHG bonus/capitalization remains unsupported. No deferred-tax Lot state machine is introduced.

Failure embeds the full Request, model digest, code and exact `subject_ids=(code.value, request.request_hash)`, and reconstructs the first failure. Outcome fields are request hash, model digest, result and failure; exactly one result/failure is allowed. Result, Failure and Outcome constructors recompute all derived authority and reject `dataclasses.replace` forgery.
